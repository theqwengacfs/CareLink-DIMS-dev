# Planning and PDCA work in progress

This is a partial implementation, not a completed feature suite.

- Weekly Planning Indicators default to the last completed Monday–Friday work week in Africa/Nairobi. Dated events use that period; standing totals remain current register figures, not historical snapshots. The displayed **provisional** 52-week rule begins week 1 one Monday before the Monday of the week containing January 1. It labels later segments beyond week 52 as additional week 52 segments, each with its actual dates. This matches the supplied example of 16–20 November 2026 as week 48, but is not the organization's confirmed rule. To avoid collisions and avoid relabelling historical reports, archive identifiers still use the existing provisional ISO week key; displayed week numbers and archive identifiers can therefore differ. Replace this convention only after the official rule is supplied and migration is designed.
- The Monday assessment tab groups scoped events by area and uses a deterministic shuffled area order; see `MONDAY-WEEKLY-REVIEW.md`. It does not yet provide a shared secretary-controlled meeting progression or confirmed physical-submission records. It still includes the whole previous Monday–Sunday for assessment coverage, so weekend clinical records are not silently hidden.
- An MCM can explicitly authorize sharing a reviewed under-120 PDCA or a 120+ PDCA that has completed its existing correction and authorization chain. The assigned caregiver or MCM can then share the immutable authorized revision. International clinical users can initiate line-anchored comment, question, clarification and evidence-request threads, with replies from international reviewers, scoped MCMs and the assigned caregiver. Commands enforce revision anchors, authorization and optimistic version checks; the discussions are advisory and do not silently modify the clinical report. Full visual and live deployment acceptance still requires verification.
- PDCA printable HTML has a foundation letterhead and logo. Word includes a text letterhead, but does not yet embed the logo; broader system-wide document branding remains incomplete.
- The daily devotion roster, seven-translation Bible reference and full document redesign are not implemented. The actual minutes template is to be supplied later; existing minutes/template features require further work before they can be considered a durable, shared official workflow.
- Secure hosted offline login and refresh after loss of network remain blocked as described in `OFFLINE_SECURITY_REQUIREMENTS.md`; the shell alone is not offline clinical access. No claim of full offline synchronization, safety or data retention is made.
